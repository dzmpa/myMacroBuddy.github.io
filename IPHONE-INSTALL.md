# iPhone Install

This app is packaged as a PWA.

To use it on iPhone:

1. Upload the folder contents to any static host such as Netlify, GitHub Pages, or Cloudflare Pages.
2. Open the hosted URL in Safari on iPhone.
3. Tap `Share` -> `Add to Home Screen`.
4. Launch it from the Home Screen like an app.

Notes:

- Opening the files directly from the Files app will not enable the service worker/offline mode.
- If USDA demo access hits its rate limit, add your own USDA API key inside the app settings.
